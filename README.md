# Garden Manager

Garden Manager is an open-source project that helps you to manage your garden ( What a surprise :) )

Here is the planned feature set for the initial release:

- [x] Authentication
- [x] OpenID Connect authentication
- [ ] Base data management
  - [x] Sellers
  - [ ] Plants
  - [ ] Purchases
- [ ] Garden management
  - [ ] Location 
  - [ ] Zones
  - [ ] Beds
  - [ ] Planting
- [ ] Plant tracking
  - [ ] Generic records
  - [ ] Pruning
  - [ ] Diseases / pests / Damages (freeze/wind/flooding)
  - [ ] Spray / Nutrition tracking
- [ ] Reminders
  - [ ] Multi-platform notifications

This hopefully help you to get a high level overview and 
health status of your garden. 

In the long run we can predict events and
help to prevent that, like preparing for extreme weather events, or prepare you
for the battle with pests.
